# 밤실 공방 · 이미지 에셋 팩 1.0

제작일: 2026-10-18. 이 팩은 기존 설계서 1.0과 15장 실행 프롬프트를 기준으로 만든 독립 게임용 미술 납품물입니다. 참고작의 이미지·캐릭터·음악·로고와 교재 원본 PNG는 포함하지 않았습니다.

## 바로 사용하는 파일

- `asset_manifest.json`: 모든 자산의 ID, 경로, 실제 크기, 앵커, 상태, 역할, SHA-256, 검수 상태
- `backgrounds/`: 4개 장면의 1536×1024 원화 PNG
- `characters/`: 여울 6자세, 솜새 3자세의 투명 PNG
- `objects/`: 실빛다리·반달 온실·접히는 방·구름 우체역의 분리형 SVG/PNG, 꽃의 투명 원화 4단계
- `ui/`: 동작·접근성 아이콘, 버튼 4상태, 매듭 피드백. 기본·고대비 변형 포함
- `education/`: 6개 개념 도식과 4개 고급정보 변형. 기본 도식에는 tick 수를 숨김
- `previews/night_thread_asset_overview.png`: 전체 미술과 조합 예시
- `previews/night_thread_pose_alpha_board.png`: 밝고 어두운 바탕에서 투명도·상태 확인
- `source/`: 벡터 생성·렌더 코드, 정규 레벨 데이터, 미리보기 조합 코드
- `docs/`: 세부 사용 지침, 폰트 라이선스, 검수 기록

PNG와 SVG는 한 장짜리 콘셉트 시트를 잘라 쓰는 형식이 아닙니다. 각각 별도 파일이며, SVG 원본과 PNG 렌더는 같은 논리 자산의 두 표현입니다. 생성 원화 PNG는 손실 없는 원본 그대로 보존했습니다.

## MVP 포함 범위

92개 논리 자산: 생성 원화 17개(배경 4, 캐릭터 9, 꽃 4)와 정밀 벡터 75개. 벡터는 SVG와 PNG를 모두 제공합니다. 벡터 75개는 장면 오브젝트 35, UI/상태 30, 교육 도식 10으로 구성됩니다. 꽃은 질감 원화 4단계와 저용량 벡터 4단계 중 한 세트를 선택해 사용합니다.

여울 상태: idle / prepare / press / hold / release / miss.
솜새 상태: count / demo / encourage.
꽃 원화 상태: closed / opening_1 / opening_2 / open.

이는 상태별 정지 키포즈입니다. 완성된 관절 리그·프레임 애니메이션·음향·게임 실행 코드는 포함하지 않습니다. 스프라이트 교체, 위치 보간, 앵커 조정 및 최종 기기 검수는 구현 단계에서 진행합니다.

## 장면과 레벨 연결

- 실빛다리: L01–L03. 시작은 채운 원, 끝은 빈 원, 붙임줄 경계는 납작한 직물 매듭입니다. 경계에서 새 attack·클릭·반짝임을 만들지 않습니다.
- 반달 온실: L04–L05. 정확한 2칸 물통과 1칸 이슬병, 3칸 시간 띠를 사용합니다. 꽃잎 수나 생성 그림의 면적을 정답으로 쓰지 않습니다.
- 접히는 방: L06–L07. 같은 6타일을 각각 2+2+2와 3+3으로 묶습니다. 타일 크기와 작은 박의 시간은 같습니다.
- 구름 우체역: L08–L09. 편지 외형과 순서는 같습니다. 기준 4분음표의 BPM만 72→108로 바뀝니다.

## 화면 배치

배경은 장식 레이어이고, 판정 객체는 별도 레이어입니다. 모바일 장면은 4:3, 데스크톱은 16:9로 중앙 크롭할 수 있습니다. 정확한 cropRect는 manifest에 기록했습니다. 플레이 화면 전체를 단순 축소하지 말고 표적과 입력영역을 재배치하세요.

- 중앙 공통 안전영역: 원화 x22–78%, y36–66%. 큰 상호작용 표적은 이 구역 중심에 배치
- 4:3 크롭: x=85.333, y=0, w=1365.333, h=1024
- 16:9 크롭: x=0, y=80, w=1536, h=864
- 실빛다리 A와 접히는 방 C의 맨 위 달 장식 일부는 16:9에서 잘립니다. 게임 신호는 포함하지 않습니다
- 배경은 원래 정지 이미지이므로 움직임 축소 모드에서도 같은 파일을 사용. 배경 이동·입자만 끄기
- 액션 버튼 최소72 CSS px 높이, 보조버튼 최소44×44, 기본 본문16px. 중요한 설명·선택지는 실제 DOM 텍스트/버튼으로 유지
- 빈 놓기 원의 중심 뒤로 리본을 통과시키면 채운 신호처럼 보입니다. 리본을 원 앞에서 끝내거나 별도 마스크를 사용해 가운데를 비우기

## 앵커와 투명도

원화 스프라이트는 1254×1254 RGBA이고 바깥에 여백이 있습니다. manifest의 픽셀 앵커를 우선 사용하세요. 여울은 공통 발밑 기준점 (670,1178), 꽃은 화분 바닥 (667,1170)을 초기값으로 제공합니다. 실제 화면에서 포즈 전환 시 1–2px 보정이 필요할 수 있습니다. 솜새는 각 파일의 추천 발 앵커를 사용합니다.

원화에는 생성기 특유의 매우 낮은 alpha=1/255 주변 잔여 픽셀이 있을 수 있습니다. 원본을 임의로 수정하지 않았고, raw alpha bounds와 alpha≥128 visible bounds를 함께 기록했습니다. 밝은 종이색·어두운 남색 위에서 정지 조합을 확인했습니다. atlas 자동트림은 alpha>0 바운드만 믿지 말고 낮은 알파 처리·테두리 샘플링을 구현 환경에서 점검하세요.

## 모바일 용량

원화·SVG를 보존한 제작용 마스터 팩입니다. 네 배경을 한꺼번에 미리 로드하지 마세요. 첫 장면에 필요한 배경·오브젝트·포즈만 읽고 다른 장면과 고급 도식은 지연 로드하세요. 모든 마스터를 동시에 GPU 텍스처로 올리면 모바일 메모리 예산에 불리합니다. 최종 빌드에서는 실제 화면 크기에 맞는 전달용 해상도·압축 포맷·텍스처 atlas를 별도 검수해야 합니다. 이 팩으로 8MB 초기 로드 목표나 모바일 성능을 달성했다고 주장하지 않습니다.

## 교육·출시 검수

기하·데이터 검증 및 정지 이미지 시각 검수는 수행했습니다. 물통의 실제 색상 채움은 12,288:6,144 픽셀로 2:1입니다. 음악 도식은 PPQ480, 점4분720, 3/4와6/8의1440 tick, 같은 패턴의72/108 BPM 비교를 따릅니다.

최종 교육자 악보 검수, 청음, 접근성 사용자 검사, 런타임 상태 전환, 실제 iPhone/Android 및 브라우저 성능 검수는 아직 하지 않았습니다. 교육 도식의 `releaseApproved`는 false이고 `notationReview`/`listeningReview`는 pending입니다. 출시승인 상태를 자동으로 true로 바꾸지 마세요. 그림 픽셀에서 정답 시각을 추론하지 말고 정규 데이터로 계산하세요.

## 재생성·검증

기본 Python 3 + Pillow + Inkscape 1.4 환경에서:

    python source/build_vectors.py --render
    python source/build_preview.py
    python source/build_pack.py

세부 렌더링과 고대비/DOM 라벨 사용법은 `docs/VECTOR_GUIDE.md`를 참고하세요. 생성 그림의 정확한 프롬프트와 출처는 `image_generation_manifest.json`, `backgrounds/background_generation.json`, `characters/somsae_generation.json`에 있습니다. 재생성하는 모델 호출은 같은 픽셀을 보장하지 않으므로 배포 파일은 manifest의 해시로 고정하세요.

## 권리와 의존성

원화는 이번 작업에서 새로 생성했고 벡터는 새 코드로 제작했습니다. 제3자 상업 게임 자산과 교재 원본은 포함하지 않았습니다. 생성물의 독점적 저작권 성립·상표 등록 가능성을 보장하지 않습니다. 교육 도식에 사용한 Noto/DejaVu 글리프의 라이선스를 `docs/`에 함께 보관했습니다. 폰트 파일 자체는 포함하지 않으며 SVG는 글리프 윤곽을 포함합니다. 최종 상용 배포 전 사용자의 권리·교육 검수를 거치세요.
